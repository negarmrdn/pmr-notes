# ISNCSCI exam & AIS classification

<div class="sample-banner">Sample note to show the format. Edit it, keep it, or delete it.</div>

!!! abstract "At a glance"
    The ISNCSCI exam (from ASIA and ISCoS) is a standardized motor, sensory and anorectal exam. From it you work out the sensory, motor and neurological levels and the AIS grade (A–E). The current edition is the **2019 revision**.

    Classify in this order: **sensory levels → motor levels → NLI → complete or incomplete → AIS grade → ZPP**.

## The exam

**Sensory.** 28 dermatomes per side (C2 to S4–5), each tested for light touch (LT) and pin prick (PP).

| Score | Meaning |
|---|---|
| 0 | Absent |
| 1 | Altered (impaired *or* heightened) |
| 2 | Normal |
| NT | Not testable |

**Motor.** 10 key muscle functions per side, graded 0–5.

| Level | Key muscle function |
|---|---|
| C5 | Elbow flexors |
| C6 | Wrist extensors |
| C7 | Elbow extensors |
| C8 | Finger flexors (distal phalanx of the middle finger) |
| T1 | Small finger abductors |
| L2 | Hip flexors |
| L3 | Knee extensors |
| L4 | Ankle dorsiflexors |
| L5 | Long toe extensors |
| S1 | Ankle plantar flexors |

**Anorectal.** Voluntary anal contraction (VAC) and deep anal pressure (DAP), each scored yes or no.

## Levels

- **Sensory level** (each side): the most caudal dermatome with normal (2) LT **and** PP, with every dermatome above it also normal.
- **Motor level** (each side): the lowest key muscle graded **≥3**, provided every key muscle above it is **5**. Where there's no key muscle to test (C1–C4, T2–L1, S2–S5), the motor level is taken to be the same as the sensory level, as long as motor function above it is normal.
- **Neurological level of injury (NLI):** the most rostral of the four levels (right and left sensory, right and left motor).

## Complete vs incomplete

**Sacral sparing** decides it. Any one of these makes the injury **incomplete**:

- LT or PP at S4–5 (either side)
- DAP
- VAC

No sacral sparing means **complete (AIS A)**.

## AIS grades

| Grade | Name | Definition |
|---|---|---|
| **A** | Complete | No sensory or motor function in S4–5 |
| **B** | Sensory incomplete | Sensory but not motor function below the NLI, including S4–5 (LT, PP or DAP), **and** no motor function more than 3 levels below the motor level on either side |
| **C** | Motor incomplete | Motor function below the NLI, with **fewer than half** of key muscles below the NLI graded ≥3 |
| **D** | Motor incomplete | **At least half** of key muscles below the NLI graded ≥3 |
| **E** | Normal | Normal sensory and motor exam in someone who previously had deficits |

**Motor incomplete** (AIS C or D) requires either:

1. **VAC**, or
2. **Sacral sensory sparing plus motor function more than 3 levels below the motor level** on either side (each side counted from its own motor level). Since 2019, non-key muscle functions can be used for this step.

## Zone of partial preservation (ZPP)

The most caudal segment on each side that still has some function.

- **Motor ZPP** is recorded when **VAC is absent**.
- **Sensory ZPP** is recorded when there's **no S4–5 sensation and no DAP**.

Since 2019, ZPP isn't limited to AIS A. It applies whenever those sacral functions are absent, so it can also be recorded in some incomplete injuries.

## High-yield for boards

!!! tip "Board pearls"
    - **C vs D:** count key muscles below the **NLI**.
    - **B vs C:** look more than 3 levels below the **motor level** on each side.
    - DAP alone is enough to make an injury sensory incomplete.
    - AIS E is only used when there were deficits before. A normal first exam isn't "AIS E".
    - In AIS B, preserved **pin prick** sensation is a favorable sign for regaining walking.

!!! warning "Easy to mix up"
    - A sensory score of 1 means *altered*, which can be impaired **or** heightened.
    - The motor level needs the key muscles **above** it to be 5, not just ≥3.
    - The NLI is the **most rostral** of the four levels, not an average.

## Clinical pearls

!!! example "From the wards"
